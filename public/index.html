00 / PROJECT

법규검토 워크스페이스

조회 자료 · 열람용

지번으로 자료를 모으고, 근거 조문을 대조하여 검토 문서와 설계 기초자료를 구성합니다.

자료 연결 안내 (로그인 불필요)
  • 이 사이트는 별도 로그인 없이 사용합니다. 기관 열쇠(API 키)는 사이트에 미리 등록되어 있습니다.
  • 주소(카카오)와 건축물대장(공공데이터포털)은 사이트 서버가 조회합니다.
  • 법령·조례 현행 원문(법제처)과 토지이용계획·지적(브이월드)은 기관 정책에 따라 사용 중인 브라우저가 해당 기관에서 직접 받아옵니다. 회사 보안망에서 law.go.kr 또는 vworld.kr 접속이 차단되어 있으면 해당 항목이 공란으로 표시되므로, 다른 인터넷 환경에서 사용하십시오.
  • 입력한 주소와 조회 결과는 서버에 저장하지 않습니다.

빨간 글씨는 수동 입력·가정·원문 미대조 사항입니다. 수집하지 못한 수치는 공란으로 남깁니다. 입력 자료는 서버에 저장하지 않습니다.

이 기기에 맑은 고딕이 설치되지 않아 화면·PDF에 대체 글꼴이 적용될 수 있음. 맑은 고딕 설치 기기에서 출력할 것.

07 / DRAWING DATA

도면 자료

주소를 조회하면 대상 필지·주변 필지(지번 표기)·주변 건물이 자동으로 들어갑니다. 바로 [DXF 받기]를 누르면 됩니다.

지형 한눈에 보기

주소를 조회하면 지형 높낮이가 색으로 표시됩니다.

도면 파일 사용법 (DWG·SKP로 바꾸기)

① CAD 2D — DXF → DWG

  1. [DXF 받기]로 파일을 내려받습니다.
  2. AutoCAD에서 파일 → 열기, 파일 형식을 DXF(*.dxf)로 바꿔 엽니다.
  3. 다른 이름으로 저장 → 파일 형식 AutoCAD 도면(*.dwg)을 고르면 DWG가 됩니다.
  4. AutoCAD가 없는 PC: 무료 프로그램 ODA File Converter로 DXF를 DWG로 바꿀 수 있습니다.

레이어: 대상필지(빨강) · 주변필지 · 지번문자 · 도로 · 주변건물. 단위는 m입니다. mm 단위 도면에 붙일 때는 SCALE 1000을 적용하십시오.

② 스케치업 3D — DAE → SKP

  1. [지형 DAE] 또는 06구역 [스케치업 DAE]로 파일을 내려받습니다.
  2. SketchUp에서 파일 → 가져오기, 파일 형식 COLLADA 파일(*.dae)을 골라 엽니다.
  3. 파일 → 다른 이름으로 저장하면 SKP가 됩니다.

SketchUp Pro(설치형) 기준입니다. 단위는 m이며, 가져오기 전 [옵션]에서 단위를 미터로 맞추면 크기가 정확합니다.

DWG·SKP는 제작사 비공개 형식이라 사이트에서 직접 만들지 않습니다. 위 방법으로 바꾸면 원본 형식 그대로 사용할 수 있습니다. 지형 높이는 공개 수치표고(약 30 m 간격) 기반 개략값으로 실제와 다를 수 있습니다.
