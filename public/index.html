00 / PROJECT

법규검토 워크스페이스

조회 자료 · 열람용

지번으로 자료를 모으고, 근거 조문을 대조하여 검토 문서와 설계 기초자료를 구성합니다.

자료 연결 안내 (로그인 불필요)
  • 이 사이트는 별도 로그인 없이 사용합니다. 기관 열쇠(API 키)는 사이트에 미리 등록되어 있습니다.
  • 주소·지도(카카오), 건축물대장(공공데이터포털), 토지이용계획(브이월드)은 사이트 서버가 조회합니다.
  • 법령·조례 현행 원문은 국가법령정보센터 정책에 따라 사용 중인 브라우저가 법제처(law.go.kr)에서 직접 받아옵니다. 회사 보안망에서 law.go.kr 접속이 차단된 경우 법령 항목이 공란으로 표시되므로, 이때는 다른 인터넷 환경에서 사용하십시오.
  • 입력한 주소와 조회 결과는 서버에 저장하지 않습니다.

빨간 글씨는 수동 입력·가정·원문 미대조 사항입니다. 수집하지 못한 수치는 공란으로 남깁니다. 입력 자료는 서버에 저장하지 않습니다.

이 기기에 맑은 고딕이 설치되지 않아 화면·PDF에 대체 글꼴이 적용될 수 있음. 맑은 고딕 설치 기기에서 출력할 것.

02 / LAND USE

수동 입력 · 복수 필지

API 수신값과 구분하여 빨간 글씨로 출력합니다. 수치가 없는 칸은 비워 둡니다.

원본 엑셀의 대지 합계 수식은 첫 두 필지만 합산함. 3필지 이상은 엑셀에서 원본 수식 검토 대상. 수식은 임의 변경하지 않음.

03 / BUILDING REGISTER

건축물대장

세움터 열람·발급건축HUB 자료 출처
표제부·층별 현황·변동사항 수동 입력

소유자 성명·주민등록번호를 입력하지 않습니다. API 실패와 실제 0건 응답은 구분됩니다.

04 / CODE REVIEW

법규 검토

지구단위계획 → 지자체 조례 → 국가 법령 상한 순서. 링크는 화면에만 표시합니다. 시행일 공란은 현행 원문을 수신하지 못한 항목입니다.

적용값·현장 조건 입력

법적 제재 유의사항

판단 자료 전달 · 판단 내용 반영

외부 AI 호출 기능 없음. 붙여넣은 판단은 빨간 글씨로 문서에 수록됩니다.

05 / DESIGN OUTLINE

설계 개요

최대 면적은 입력 면적과 적용 비율의 산술 상한입니다. 건축선·일조·지구단위계획·허용 용도 등에 의한 실제 설계 가능 규모와 다를 수 있습니다. 엑셀의 별도 계획 수치 입력칸은 비워 둡니다.

06 / VOLUME STUDY

3D 볼륨 스터디

법정 기준에 따른 가정 모델이며 설계안이 아님.

모델 조건 · 실제 필지 경계
대상 필지의 실제 경계를 연결하십시오.

마우스·터치 드래그 회전 / 휠·두 손가락 확대. 실제 경계 없이 예시 대지를 생성하지 않습니다.

07 / DRAWING DATA

도면 자료

단위 m · 대상 필지 중심 WGS84 접평면(동·북) 좌표. 법정 측량 좌표계와 구별됩니다. 지목 ‘도로’ 경계는 도로로 분류되며 건축법상 도로 판정을 대신하지 않습니다.

EPSG:4326 좌표. 필지 properties.pnu가 입력 PNU와 같거나 target:true인 도형을 대상 필지로 사용합니다. 높이 height(m) 또는 층수 floors가 있으면 주변 매스에 반영합니다.
