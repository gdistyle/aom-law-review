지형 한눈에 보기

주소를 조회하면 지형 높낮이가 색으로 표시됩니다.

도면 파일 사용법 (DWG·SKP로 바꾸기)

① CAD 2D — DXF → DWG

  1. [DXF 받기]로 파일을 내려받습니다. (AutoCAD 2007 이상 형식, 한글 레이어·지번 문자 포함)
  2. AutoCAD에서 파일 → 열기, 파일 형식을 DXF(*.dxf)로 바꿔 엽니다.
  3. 다른 이름으로 저장 → 파일 형식 AutoCAD 도면(*.dwg)을 고르면 DWG가 됩니다.
  4. AutoCAD가 없는 PC: 무료 프로그램 ODA File Converter로 DXF를 DWG로 바꿀 수 있습니다.

레이어: 대상필지(빨강) · 주변필지 · 지번문자 · 도로 · 주변건물. 단위는 m입니다. mm 단위 도면에 붙일 때는 SCALE 1000을 적용하십시오.

② 스케치업 3D — DAE → SKP

  1. [지형 DAE] 또는 06구역 [스케치업 DAE]로 파일을 내려받습니다.
  2. SketchUp에서 파일 → 가져오기, 파일 형식 COLLADA 파일(*.dae)을 골라 엽니다.
  3. 파일 → 다른 이름으로 저장하면 SKP가 됩니다.

SketchUp Pro(설치형) 기준입니다. 단위는 m이며, 가져오기 전 [옵션]에서 단위를 미터로 맞추면 크기가 정확합니다.

DWG·SKP는 제작사 비공개 형식이라 사이트에서 직접 만들지 않습니다. 위 방법으로 바꾸면 원본 형식 그대로 사용할 수 있습니다. 지형 높이는 공개 수치표고(약 30 m 간격) 기반 개략값으로 실제와 다를 수 있습니다.
