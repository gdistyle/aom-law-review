## 원본 검토 기록

인수인계서 전 장, 빈 Word/Excel/목차 XML, 예시 Word(.doc), 예시 Excel(.xls)의 11개 시트 구조와 값·수식 기록, 표제부 PDF 5쪽, 전유부 PDF 2쪽, 도장 HTML을 읽고 구조를 검토했다. 예시 .xls는 OLE/BIFF 레코드로 읽었으며 출력 양식 재저장에 사용하지 않았다. 예시 PDF의 개인정보·직인·발급번호는 코드 저장소에 포함하지 않는다.

## 충돌·유보 사항

원본 도장 기능 보존과 모든 글꼴 맑은 고딕 강제는 동시에 만족할 수 없어 도장 원본 유지 원칙을 적용했다. Word 원본의 고정 페이지 구성도 유지했다. Excel 원본의 첫 두 필지 합계 수식은 보존했으며 다필지 경고를 제공한다. 조례 별표 API 제공 한계를 자동 텍스트 생성으로 보완하지 않는다. 면적÷층고로 층수를 계산하는 식은 단위 오류이므로 면적÷층바닥면적으로 수정했다.

전체 화면과 출력 경로를 포함하되, 미확정 연결을 성공한 자동 조회처럼 표현하지 않는다. 실키가 없는 상태에서 인수인계서 8장의 실기관 수용 판정을 모두 통과했다고 주장하지 않는다.
