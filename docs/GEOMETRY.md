# 좌표·지형·볼륨 산정

## 경계 입력 계약

VWorld 자동 응답 또는 직접 확인한 EPSG:4326 GeoJSON Feature/FeatureCollection을 사용한다. 대한민국 범위 경도 124–132, 위도 32–40으로 제한한다. 다음은 형식 설명용 합성 좌표이며 실제 지번의 경계가 아니다. 실제 설계 자료에 그대로 사용하지 않는다.

```json
{
  "type": "FeatureCollection",
  "features": [{
    "type": "Feature",
    "properties": {"target": true, "pnu": "", "jibun": "합성 형식 예시", "category": ""},
    "geometry": {"type": "Polygon", "coordinates": [[[127,37],[127.0004,37],[127.0004,37.0003],[127,37.0003],[127,37]]]}
  }]
}
```

자동 자료는 PNU가 정확히 같은 필지를 선택한다. 수동 자료는 `target:true`로 대상을 지정한다. 주변 건물은 실제 높이 `height`(m), 실제 지상층수 `floors` 중 수집한 필드만 쓴다. 높이가 없고 층수만 있으면 3m×층수는 빨간 가정으로 표시한다. 둘 다 없으면 높이를 임의 생성하지 않는다. 지목 `도` 또는 도로로 확인한 필지만 DXF 도로 레이어로 분류한다.

## 계산 과정

WGS84 타원체의 ECEF를 거쳐 필지 중심 ENU(East, North, Up) 미터 좌표를 만든다. 지적 경위도를 도 단위 그대로 미터로 쓰지 않는다. 이 좌표는 EPSG:5179 등 국가 평면좌표계와 동일하지 않다.

폴리곤 외곽과 홀을 삼각분할하고 후퇴 구간을 차집합으로 제거한다. 볼록·오목·홀·다중 폴리곤을 처리한다. 자기 교차 등 비정상 경계는 거부한다. 다중 필지가 중첩하는 입력은 먼저 지적 자료에서 정합성을 정리해야 한다. 필지 간 겹침을 토지면적 증가로 인정해서는 안 된다.

대지 안의 공지 이격, 실제 도로측 경계 번호와 후퇴량을 적용한다. 0은 확인된 무후퇴를 사용자가 입력하는 값이고 공란은 미정이다. 모서리 이격은 16각형으로 보수적으로 잘라내므로 수학적으로 완전한 원호 offset보다 면적이 조금 줄 수 있다.

건축면적 상한 = 공부상 대지면적×적용 건폐율. 연면적 상한 = 공부상 대지면적×적용 용적률. 층별 바닥면적을 누적하여 연면적 상한에서 잘라낸다. 층수는 연면적/층바닥면적, 높이는 층수×층고로 산정한다. 용적률 제외면적·지하층 등은 미확정 계획 수치이므로 임의로 추가하지 않는다.

주거지역은 사용자가 선택한 실제 정북측 경계를 기준으로 각 층 상단 높이에서 일조 이격을 적용한다. 현행 원문에서 분기높이·저층 이격·높이당 비율을 읽거나 사용자가 직접 입력한다. 정북 경계 후보 표시만으로 최종 경계를 자동 확정하지 않는다. 곡선·복잡한 도로·법령상 예외·지형 높이차까지 통합한 건축법 허가 검토 엔진은 아니다.

최대 모델과 일자·ㄱ자·중정 모델을 별도 생성한다. 중정은 실제 경계에서 내부가 성립할 때만 생성한다. 너무 작거나 이격으로 소멸하면 해당 안을 억지로 만들지 않는다. 각 안의 층수·건축면적·연면적·비율을 실제 생성된 조각에서 합산한다. 최대 모델은 선택된 보수적 바닥·층 구성에 따른 상한 모델로, 모든 평면 배치를 최적화한 전역 최대해가 아니다. 계산 보호 상한 80층은 법령상 제한이 아니며 적용 높이를 모르면 무제한으로 확정하지 않는다.

고정 문구: 법정 기준에 따른 가정 모델이며 설계안이 아님.

## 표시와 파일

three.js 0.180.0과 같은 버전 OrbitControls를 사용한다. CDN을 못 읽으면 내장 Canvas가 동일 삼각형을 회전·확대하여 표시한다. 이 대체 경로는 계산값이나 도형을 바꾸지 않는다. three.js 네트워크 경로와 SketchUp 실가져오기는 실배포 후 검수한다.

DXF는 R2000 AC1015, 단위 m, 대상필지 빨강과 주변필지·지번문자·도로·주변건물 5개 레이어이다. 한글 문자는 DXF Unicode escape를 사용한다. DAE는 COLLADA 1.4.1, meter=1, Z_UP이다. 여러 매스안은 겹치지 않도록 표시 오프셋을 두며 절대 필지 위치의 시공 모델로 사용하지 않는다. 삼각분할 조각의 내부 공유면이 남을 수 있어 위상적으로 단일 수밀 솔리드가 보장되지 않는다.

## 공개 DEM

AWS Terrain Tiles Terrarium z12, 대상 중심 17×17 화소를 표본으로 사용한다. R×256+G+B/256−32768 식을 사용하며 미수록 화소는 0으로 바꾸지 않는다. 지형 DAE는 DEM 표고 기준, 볼륨 DAE는 z=0 가정 기준이다. 두 파일을 설계 기준고로 정합하려면 실제 측량 기준고를 별도로 적용해야 한다. 서로 다른 원천 DEM의 수직 기준과 자료 시점을 임의로 단정하지 않는다.

지형 높이는 공개 수치표고자료(해상도 약 30 m) 기반의 개략값으로, 실제 지반고·현황과 다를 수 있음. 정밀 검토 시 현황측량 또는 국토지리정보원 수치지형도 기준으로 재검토할 것.
