## 단위 시험 범위

PNU 일반/산 구분, 본부번 0 채움, 0과 null 분리, 실제 달력 날짜와 미래 시행일 제외, 미확정 다필지 합산 방지, 조문 링크 강제, 기준값의 무근거 적용 방지, 단일 조례 수치 추출, 조례 우선·상한 fallback 색상, 지구단위계획 수치 공란, 광역시/자치구 관할, 조문 가지번호, 조건부 법규·제재, 판단 붙여넣기, Excel 자체닫힘 셀·인접 수식 보존, Word editable XML, URL·등록번호 패턴 제거, 조경 면적 기준의 현행 대조, 도로 입력 조건 반영을 시험했다.

기하 시험은 오목 경계·홀·면적 제한·경계 이격·일조 절단·자기 교차 거부·컨셉별 면적·파일 단위를 포함한다. Worker 시험은 비밀키 비노출, 입력·출처 제한, 기관 오류/0건 분리, 개인 필드 제거, 법령 현행 요청 및 미확정 레이어 동작을 mock 응답으로 검사한다. Mock 시험은 실기관 계약 검증과 다르다.

## 브라우저 시험의 환경 제한

현재 실행 환경의 Chromium은 외부/로컬 URL 페이지 이동이 관리 정책으로 제한되어 있었다. 정책을 변경하지 않았으며, `tests/offline_harness.py`가 로컬 HTML과 JavaScript 모듈을 메모리 DOM으로 읽어 같은 화면·계산·다운로드를 실행했다. 로컬 파일 및 무키 `/api/config`만 시험 브리지로 연결했다. 카카오 SDK·three.js CDN·법령 서버로의 실제 접속은 이 시험에서 수행하지 않았다.

따라서 이 결과는 오프라인 DOM 및 출력 생성 회귀 시험이다. HTTPS 배포, 브라우저 교차 출처 동작, 외부 CDN 로딩과 기관 승인키를 포함한 종단간 검수로 확대 해석하지 않는다. 정상 개발 환경에서는 `AOM_OFFLINE_RENDER` 없이 `browser_smoke.py`를 실행할 수 있다.

## 문서 시각 검수

Word 출력물을 LibreOffice 기반 렌더러로 9쪽 렌더링하여 표지·목차·표·머리글·바닥글의 배치를 점검했다. 원본 고정 배치에 의한 표지/목차 사이 빈 페이지가 나타났고 원본 구조를 임의 삭제하지 않았다. 이 환경에는 맑은 고딕이 없으므로 최종 글꼴·줄바꿈 동일성은 Microsoft Word와 해당 글꼴 환경에서 확인해야 한다. Excel은 LibreOffice로 재저장하지 않았으며 OOXML 비교로 수식·서식 구조를 검증했다. Excel 실제 재계산/인쇄 미리보기는 미실행이다.

제공된 빈 Excel의 이전 작성자 귀속 공유 문자열 1개를 비웠다. 해당 위치 변경 외 원본의 수식·스타일을 유지했다. 출력 시 빨간색은 기존 스타일 복제 후 추가한 색상이며 원본 스타일 노드를 덮어쓰지 않는다.

## 아직 완료 판정하지 않은 항목

- 실제 하남시 감이동 440-2 API 조회 결과와 예시 대장 일치 여부.
- 기관별 인증 승인·도메인 설정·쿼터 소진 상태·실제 응답 전체 페이지 수집.
- 현행 원문과 각 링크가 도착하는 조문·시행일의 사람에 의한 대조.
- VWorld 주변 건물 서비스 및 속성, 토지이음 PNU 직접 링크, 변동사항 API의 현재 계약.
- 실제 타일/경계로 생성한 DAE의 SketchUp 가져오기 및 측량 좌표·표고 정합.
- 맑은 고딕 환경의 MS Office 최종 출력 검수, 모바일 실기기 지도·다운로드.
- Cloudflare 실제 계정 배포 및 무료 한도 내 운영.

모든 화면·출력 모듈과 시험 코드는 포함했으며, 위 연결·검수 유보 사항을 예시값이나 임의 API로 대체하지 않았다. 인수인계서 8장의 최종 수용 판정은 README 체크리스트에 따라 수행한다.
