# A.O.M 법규검토 사이트

지번 검색, 토지이용계획·건축물대장 조회, 현행 법령 대조, 문서 출력, CAD·지형·볼륨, 원본 도장 도구를 하나의 Cloudflare Worker와 정적 화면으로 구성한 소스 저장소이다. 작성자 기본값은 이오상이다.

이 저장소에는 실사용 인증키가 없다. 키가 없어도 수동 입력과 문서 다운로드가 작동한다. 실제 기관 응답, 법령 링크의 최종 도착 조문, Cloudflare 실배포를 검수 완료로 표시하지 않았다. 기관 인증 후 아래 8장 체크리스트를 수행한다.

## 1. 시작

Node.js 22 이상에서 별도 npm 패키지 설치 없이 로컬 화면·단위 시험을 실행한다.

```sh
npm test
npm run check
npm run dev
```

브라우저에서 `http://localhost:8787`을 연다. HTML 파일을 더블클릭하는 `file://` 실행은 지원하지 않는다. `npm run dev`는 개발용 정적 서버와 동일한 API 중계 코드를 사용한다. 인터넷이 없는 환경에서는 지도·현행법령·기관 조회 없이 수동 입력 및 문서 출력만 사용한다.

키를 넣을 경우 `.dev.vars.example`을 `.dev.vars`로 복사한 뒤 값을 채운다. `.dev.vars`는 Git에 올리지 않는다. 로컬 서버는 시작할 때 환경변수를 읽으므로 수정 후 재시작한다.

## 2. 저장소 구조

```text
public/
  index.html                  법규검토 화면·수동 입력·출력 버튼
  _headers                    정적 자산 보안 헤더
  assets/                     화면 CSS·원본 A.O.M 로고
  js/
    app.js                    화면·조회·지도·도장 탭 연결
    core.js                   공통 모델·PNU·빈값·날짜·문자열 처리
    legal.js                  현행 법령 정규화·규칙·조례·법적 제재
    ooxml.js                  원본 DOCX/XLSX XML 채우기
    pdf.js                    브라우저 Canvas 기반 PDF 생성
    geometry.js               실제 경계·이격·일조 절단·모델·DEM
    scene.js                  three.js 및 오프라인 Canvas 표시
    cad.js                    DXF·COLLADA DAE
    exports.js                개별 파일·전체 ZIP·출처 기록
  stamp/index.html            제공된 도장 도구 원본 그대로
  templates/                  빈 양식 3개
  vendor/                     JSZip 3.10.1 및 라이선스
src/worker.js                 /api/* 기관 API 중계
scripts/dev-server.mjs        의존성 없는 로컬 실행
scripts/check.mjs             구문·필수 파일·도장 무결성 검사
wrangler.jsonc                Workers Assets·환경변수 설정
.dev.vars.example             로컬 비밀키 예시, 실제 값 없음
package.json                  로컬·시험·배포 명령
THIRD_PARTY_NOTICES.md         라이브러리·데이터·원본 자산 안내
assets-manifest.json           제공 자산 해시 및 변경 내역
requirements-qa.txt            선택 브라우저 시험 의존성

 docs/                        API 재확인·요구사항 대응·기하·시험 결과
```

화면 파일만 `public/`에 있다. 시험 fixture와 개발 문서는 웹 정적 디렉터리 밖에 두었다. 첨부 예시 DOC/XLS/PDF는 구조 분석에만 사용하였고, 개인정보·직인·발급번호가 포함된 예시 원본을 배포 폴더에 복제하지 않았다.

## 3. 무료 키 4개 발급 방법

4개 기관의 인증을 의미한다. 카카오는 REST 키와 JavaScript 키가 별도이므로 실제 입력값은 비밀키 4개와 공개키 1개이다. 발급·활용 승인 및 기관별 무료 한도는 운영자가 확인한다. 키를 발급받는 행위와 특정 데이터 서비스에 활용 승인을 받는 행위는 다를 수 있다.

| 기관 | 환경변수 | 보관 |
|---|---|---|
| 카카오디벨로퍼스 | `KAKAO_REST_KEY` | Worker Secret |
| 카카오디벨로퍼스 | `KAKAO_JS_KEY` | 공개 변수·등록 도메인 제한 |
| 공공데이터포털 | `DATA_GO_KR_KEY` | Worker Secret |
| 브이월드 | `VWORLD_KEY` | Worker Secret |
| 국가법령정보 공동활용 | `LAW_OC` | Worker Secret |

### 3.1 카카오

1. <https://developers.kakao.com> 로그인 후 앱을 생성하거나 기존 앱을 선택한다.
2. 앱 관리의 카카오맵 사용 설정을 활성화한다.
3. 무료 쿼터 적용 앱인지 확인한다. 2026-10-28 확인한 공식 안내상 개발자 계정에서 처음으로 카카오맵 API를 활성화한 앱에 무료 쿼터가 제공된다. 첫 앱이 이미 있으면 그 앱을 사용하는 방안을 검토한다. 두 번째 앱이나 무료 한도 초과에 필요한 유료 API·비즈월렛을 이 프로젝트 때문에 활성화하지 않는다.
4. REST API 키를 `KAKAO_REST_KEY`, JavaScript 키를 `KAKAO_JS_KEY`에 입력한다.
5. JavaScript SDK 허용 도메인에 실제 `https://...workers.dev`와 필요한 로컬 도메인을 등록한다. 앱·키별 REST 허용 설정도 기관 안내에 따라 설정한다.
6. 카카오 무료 쿼터 뱃지와 사용량을 관리 화면에서 확인한다. 쿼터가 소진되면 수동 입력으로 전환하고 유료 호출을 자동으로 추가하지 않는다.

근거: <https://developers.kakao.com/docs/ko/kakaomap/common>, <https://developers.kakao.com/docs/ko/kakaomap/rest-api>, <https://apis.map.kakao.com/web/guide/>.

### 3.2 공공데이터포털

1. <https://www.data.go.kr/data/15134735/openapi.do>에서 `국토교통부_건축HUB_건축물대장정보 서비스`를 확인한다.
2. 로그인 후 활용신청을 진행한다. 개발계정 승인 여부, 이용 한도, 활용 가능한 오퍼레이션을 확인한다.
3. 마이페이지의 해당 활용신청 상세에서 서비스 인증키를 확인한다. 가급적 일반 인증키의 Decoding 값을 사용한다.
4. `DATA_GO_KR_KEY`에 입력한다. 코드는 인코딩 키가 입력된 경우 한 번 해제한 뒤 URLSearchParams로 인코딩하므로 이중 인코딩하지 않는다.
5. `getBrTitleInfo`, `getBrRecapTitleInfo`, `getBrFlrOulnInfo`, `getBrExposPubuseAreaInfo`를 실제 승인키로 각각 시험한다.

소유자 성명·주민번호는 Worker 허용 필드에 없으므로 화면으로 반환하지 않는다. 변동사항 전용 공개 오퍼레이션은 확인되지 않아 임의 API를 만들지 않았다. 화면의 변동사항 입력란으로 출처를 확인한 내용만 반영한다.

### 3.3 브이월드

1. <https://www.vworld.kr>에서 회원가입·로그인 후 오픈API 인증키를 신청한다.
2. 사용 목적과 실제 서비스 URL을 등록하고 무료 활용 조건을 확인한다.
3. 발급값을 `VWORLD_KEY`에 넣는다. 등록 URL과 같은 기준으로 `VWORLD_DOMAIN`을 지정한다.
4. 토지이용계획·토지특성·개별공시지가 NED와 연속지적도 데이터 API에 대한 활용 범위 및 실제 응답을 확인한다.
5. 주변 건물 레이어는 서비스 목록에서 현재 제공되는 ID와 속성명을 직접 확인하여 `VWORLD_BUILDING_LAYER`, `VWORLD_BUILDING_HEIGHT_FIELD`, `VWORLD_BUILDING_FLOORS_FIELD`에 넣는다. 확인되지 않은 값은 비워 둔다. 이 경우 경계·건물 GeoJSON 수동 입력 기능을 사용할 수 있다.

NED 서비스별 응답 구조와 총수 필드는 `src/worker.js`의 주석 및 `docs/API_RECHECK.md`를 따라 승인 후 대조한다. 총수와 자료 구조를 해석하지 못하면 완료된 조회로 위장하지 않고 오류로 처리한다.

### 3.4 국가법령정보 공동활용

1. <https://open.law.go.kr>에서 공동활용·OPEN API 이용 신청을 진행한다.
2. 필요한 법령 목록·본문 및 자치법규 목록·본문 서비스를 신청한다.
3. 승인 후 기관이 안내한 실제 API 인증값을 `LAW_OC`에 입력한다. 과거 예시의 이메일 ID를 임의로 대입하지 않는다.
4. 국가법령은 `target=eflaw`, 현행 목록은 `nw=3`, 자치법규는 `target=ordin`, 현행 목록은 `nw=1`로 요청한다. 목록·본문의 시행일을 다시 검사한다.
5. 각 키의 활용 범위, 인증값 전달 방식, 허용 접속 조건을 확인한다. 발급 승인만으로 모든 환경에서 통신이 보장되는 것은 아니다.

공식 문서:
- <https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdListGuide>
- <https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdInfoGuide>
- <https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinListGuide>
- <https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinInfoGuide>

자치법규 별표 제공 범위에는 제한이 있다. 별표를 받지 못하면 일반 규정이나 국가 상한으로 확정된 조례값을 만들어 내지 않는다.

## 4. Cloudflare 무료 배포

Workers Free 계정과 무료 `workers.dev` 주소를 사용한다. 새 유료 도메인, R2, D1, KV, 유료 AI는 필요 없다. 무료 제공량 안에서만 운영하며 유료 요금제·유료 API를 활성화하지 않는다. 앱 코드가 기관 요금제와 과금 정책까지 강제로 통제할 수는 없으므로 계정 설정이 필수이다.

### 4.1 GitHub 업로드

ZIP을 풀어 `public`, `src`, `wrangler.jsonc`, `package.json`이 저장소 최상위에 오도록 올린다. `.dev.vars`, 실제 키, 원본 개인정보 PDF, 시험 중 내려받은 업무자료는 올리지 않는다. 업로드 직전 `npm test`와 `npm run check`를 실행한다.

### 4.2 최초 배포

Wrangler는 공식 릴리스가 확인된 `4.151.0`으로 고정하였다. 저장소에서 다음 순서로 실행한다.

```sh
npx --yes wrangler@4.151.0 login
npm run deploy
```

최초에는 키가 없어도 배포할 수 있다. 배포 결과에 나온 실제 URL을 `wrangler.jsonc`의 `SITE_ORIGIN`과 `VWORLD_DOMAIN`에 입력한다. 끝의 `/`는 제외한다. `KAKAO_JS_KEY`도 입력한다. 이 세 값은 공개 변수이다.

```sh
npx --yes wrangler@4.151.0 secret put KAKAO_REST_KEY
npx --yes wrangler@4.151.0 secret put DATA_GO_KR_KEY
npx --yes wrangler@4.151.0 secret put VWORLD_KEY
npx --yes wrangler@4.151.0 secret put LAW_OC
npm run deploy
```

명령이 값을 요청할 때 붙여넣는다. 키를 명령행 인수·스크린샷·GitHub README에 쓰지 않는다. 카카오·브이월드 등록 도메인도 같은 URL로 맞춘다.

`public/`은 Workers Assets가 제공하고 `/api/*`만 Worker를 먼저 거친다. `/api/config`에는 서비스별 키 설정 여부와 공개 JavaScript 키만 반환된다. 값이 있다는 표시가 기관의 승인·정상 응답을 인증하는 것은 아니다.

CLI 외에는 Cloudflare Workers의 GitHub 연결 배포를 사용한다. 저장소 루트에서 배포 명령을 `npm run deploy`로 설정하고 별도 프런트엔드 빌드 명령은 두지 않는다. Secrets는 배포 Worker의 설정에 저장한다. GitHub에 비밀키를 넣지 않는다. 자동 배포는 이 ZIP 생성 과정에서 실제로 실행하지 않았다.

근거: <https://developers.cloudflare.com/workers/static-assets/binding/>, <https://developers.cloudflare.com/workers/configuration/secrets/>, <https://developers.cloudflare.com/workers/platform/pricing/>, <https://github.com/cloudflare/workers-sdk/releases/tag/wrangler%404.151.0>.

### 4.3 외부 호출·보안·무료 한도

브라우저는 카카오 지도 SDK와 고정 버전 three.js를 불러온다. 나머지 기관 조회는 동일 출처 `/api/*`로 중계한다. 임의 URL 프록시가 없고, GET만 허용하며, 응답 크기·시간·입력 범위를 제한한다. 법령 응답은 저장하거나 재사용하지 않는다. DEM 타일에만 별도 캐시 헤더가 있다.

IP 기준 메모리 제한은 Worker 인스턴스 단위의 보조 방어이며 전역 사용량 제한이나 인증이 아니다. 공개 인터넷 서비스의 쿼터 소진 공격을 완전히 막지 못한다. 기관 무료 한도 확인 및 필요 시 계정에서 제공하는 무료 접근 통제를 적용한다. Workers Free 자원 제한에 걸리면 요청이 실패할 수 있으며 유료 플랜으로 자동 전환하는 코드는 없다.

## 5. 사용 흐름

주소·용도·층수·작성자·날짜를 입력하고 주소 검색 결과의 필지를 선택한다. 지도 3단과 토지·대장 자료를 조회하고, 실제 수신한 현행 법령·조례에서 규칙을 적용한다. 같은 법령이라도 시행 전 개정본은 숫자 계산에 사용하지 않는다.

키가 없을 때는 프로젝트 입력 적용 후 각 수동 입력란을 채운다. 수동 입력값은 빨간색으로 표시한다. 서로 다른 주소가 입력되면 이전 필지의 대장·법령·판단·도형 상태를 지운다. 건축물 조회 실패는 `자료 연결 전`이고, 정상 응답의 총수가 0일 때만 나대지로 표시한다. 수동 나대지 선택은 사용자 입력으로 구분한다.

지구단위계획구역은 우선 적용 행이 생성되며 적용 건폐율·용적률은 비워 둔다. 시행지침 검토 선택과 실제 적용 수치를 모두 입력해야 모델·개요 계산에 반영한다. 시행령 상한만으로 지구단위계획 허용치를 대신하지 않는다.

각 법규 행에는 근거 링크와 시행일 칸이 있다. 본문을 수신하지 못한 조문은 시행일 공란과 빨간색이다. URL이 존재한다는 사실을 원문 대조 성공으로 표시하지 않는다. 판단용 자료 복사와 `[행 ID] 내용` 형태의 붙여넣기를 제공하되 사이트는 AI를 호출하지 않는다. 붙여넣은 판단은 빨간색으로 Word 비고·이슈에 들어간다. 자유문장에 소유자 이름 등 개인정보를 직접 붙여넣지 않는다. 이름을 임의로 식별해 제거하는 기능은 없다.

3D는 실제 EPSG:4326 경계를 사용한다. 자동 자료가 없으면 해당 구역에서 GeoJSON을 입력한다. `properties.pnu`를 대상 PNU와 맞추거나 실제 대상 도형에 `target:true`를 지정한다. 형상 예시는 `docs/GEOMETRY.md`를 참고한다. 실제 지번의 경계를 모르면 만들어 넣지 않는다. 이격·도로측 후퇴·높이·정북 조건을 입력하고 모델 적용을 선택한다. 자료가 없으면 가짜 필지·지형·건물을 표시하지 않는다.

## 6. 출력

| 형식 | 생성 내용 |
|---|---|
| DOCX | 원본 표지·목차·머리글·바닥글 + Ⅰ 대지개요, Ⅱ 기존건축물, Ⅲ 법규검토, Ⅳ 법적 제재 |
| XLSX | 원본 11개 시트·숨김 상태·서식·수식 보존, 지정 셀만 입력, 재계산 요청 |
| PDF 2개 | 토지이용계획 열람 자료, 건축물대장 열람 자료 |
| DXF | AC1015, 단위 m, 대상·주변 필지·지번·도로·건물 레이어 |
| DAE 2개 | 3D 지형과 경계, 법정 비율·입력 조건에 따른 최대·컨셉 매스 |
| 전체 ZIP | 위 7개 파일 + 출처목록.txt + 지형_주석.txt + 출력_자료설명.txt |

파일명은 `{지번}_{문서명}`으로 생성한다. Word·Excel·PDF에는 URL이나 하이퍼링크를 넣지 않는다. 출처 URL은 화면과 ZIP의 `출처목록.txt`에만 수록한다. PDF는 인장·발급번호 없는 조회 자료이며 증명서가 아니다. PDF 한글은 브라우저 Canvas로 래스터화되므로 검색 가능한 텍스트 PDF는 아니다.

DAE/DXF를 생성하는 시점에 필요한 경계·지형·적용 수치가 없으면 파일 구조만 생성하고 자료 부재를 주석에 적는다. 비어 있는 DAE는 SketchUp에서 표시할 객체가 없을 수 있다. 실제 경계와 조건을 입력한 뒤 다시 받는다.

## 7. 원본 보존·구현상 유의사항

### 문서와 글꼴

화면·신규 보고서 셀·Word 본문·Excel·PDF는 맑은 고딕을 지정한다. 맑은 고딕이 설치되지 않은 기기에서는 운영체제의 대체 글꼴로 표시될 수 있으며 경고를 띄운다. 폰트 파일은 배포하지 않는다. 최종 문서 검수는 맑은 고딕이 설치된 Windows와 Microsoft Office에서 수행한다.

제공된 도장 도구는 기능 변경 금지에 따라 바이트 단위로 보존했다. 따라서 원본 도구의 전서체 등 글꼴 선택 및 Google Fonts 요청도 남아 있다. 도장 도구의 글꼴을 모두 맑은 고딕으로 강제하면 원본 유지 요구와 충돌한다. 부모 화면에서 iframe의 원래 탭 버튼만 전환한다.

원본 XLSX의 공유 문자열에 남아 있던 이전 작성자 귀속 문자열 1개만 공란으로 정리했다. 셀 주소·서식·수식·공유 문자열 인덱스는 변경하지 않았다. 원본 DOCX와 목차 XML, 도장 도구의 변경 여부는 `assets-manifest.json`에 해시로 기록했다. 원본의 숨김 시트, 기존 텍스트 라벨, 생태 표준 가중치는 유지한다.

Excel 출력은 원본 XML에 값만 채우며 빨간색 표시가 필요한 셀은 기존 스타일을 복제해 색만 추가한다. 수식 1,780개는 보존하고 과거 캐시 값만 지운다. 원본 ALT-4의 `E15` 합계 수식은 토지내역 첫 2필지만 참조한다. 3필지 이상은 원본 수식 보존과 합계 정확성이 동시에 충족되지 않으므로 화면·출력 설명에 이를 명시했다. 3필지 이상 실무 사용 시 건축가가 합계 수식을 검토해야 한다. 원본 공제·합계 행을 덮지 않도록 토지내역 입력은 현재 23필지까지 허용한다. 자동 재계산 후 수식 결과가 0으로 나타나는 것과 원자료에서 0을 수집한 것은 다르다.

DOCX는 원본의 수동 페이지 나눔·여백·표지 배치를 유지한다. 현재 LibreOffice 기반 시험 렌더러에서는 표지와 목차 사이 빈 페이지가 표시되었다. 원본 고정 배치와 대체 글꼴의 영향이 있으므로 Word에서 페이지 나눔을 최종 대조한다. 표지·목차 구조를 임의로 재설계하지 않았다.

### 자동 판단의 한계

건폐율·용적률은 현행 원문에서 일치하는 지역의 단일 규정으로 추출할 수 있을 때만 사용한다. 조건부 조항, 예외, 중복 수치, 이미지 별표는 자동 확정하지 않는다. 조례 조회 실패 시에도 시행령 현행 상한을 실제로 읽은 경우에만 빨간 상한을 쓴다. 원문을 전혀 못 받으면 기준표의 값을 채우지 않는다.

지구단위계획 시행지침, 변동사항 API, 주변 건물 레이어, 토지이음 필지 직접 링크 등 인증·기관 문서 재확인이 필요한 항목은 주석 `기관 문서로 사양 재확인할 곳`과 `docs/API_RECHECK.md`에 명시했다. 임의 엔드포인트·레이어 ID를 만들어 자동 연결 완료로 표시하지 않았다.

최대 볼륨은 입력 조건을 적용한 보수적 기하 모델이다. 전체 건축 가능 공간의 정확한 최적해나 허가 보증이 아니다. 일조는 층 상단 기준 절단, 모서리 이격은 외접 다각형에 의한 보수적 절단을 사용한다. 연면적/건축면적으로 층수를 정하고 층고를 곱해 높이를 산정한다. 인수인계서의 `연면적 ÷ 층고 → 층수`는 단위가 성립하지 않아 그대로 계산하지 않았다. 지형 절대표고와 매스의 z=0 기준도 구분한다.

## 9. 시험 명령

```sh
npm test
npm run check
npm run dev
```

별도 터미널에서 선택 브라우저 시험을 수행한다. Python 3.10 이상을 권장한다.

```sh
pip install -r requirements-qa.txt
python -m playwright install chromium
python tests/browser_smoke.py
python tests/verify_exports.py .test-output/generated
```

시스템 Chromium을 사용하는 경우 `CHROMIUM_PATH`에 실행 파일 경로를 지정한다. `AOM_TEST_OUTPUT`으로 산출물을 저장소 밖으로 지정할 수 있다. `AOM_OFFLINE_RENDER=1`은 네트워크 이동이 제한된 환경용 메모리 DOM 시험이다. 실배포·CDN·기관 API 검증을 대체하지 않는다.

실기관 수용 검수 전에는 이 결과를 허가·설계의 최종 법적 판단으로 사용하지 않는다.
